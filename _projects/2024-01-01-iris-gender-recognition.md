## Overview
This project explores the use of **Deep Convolutional Neural Networks (CNNs)** to classify gender based on iris patterns. It utilizes high-resolution biometric datasets to achieve state-of-the-art accuracy in non-intrusive gender identification.

## ✨ Key Features
- **CNN Architecture**: Optimized ResNet-based model for feature extraction from complex iris textures.
- **Pre-processing Pipeline**: Automated iris localization, normalization, and enhancement.
- **Robustness**: Tested against variations in lighting, occlusion, and low-resolution images.

## 🚀 Technology Stack
- **Frameworks**: TensorFlow and Keras for model development and training.
- **Processing**: OpenCV for real-time image pre-processing.
- **Compute**: CUDA-accelerated training on NVIDIA GPUs.
